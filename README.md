# Teleham (Web)

Веб-клиент Telegram для ПК — тёмный интерфейс, аватарки, настройки.

## Возможности
- Список чатов с **аватарками**
- Переписка, поиск по чатам
- **Падающий снег** (вкл/выкл в настройках)
- **Удалённые сообщения**
- **История правок**
- Настройки (⚙), выход из аккаунта

## Запуск

1. Распакуй ZIP
2. Запусти **`start_web.bat`**
3. Открой **http://127.0.0.1:8080**

Окно сервера не закрывай.
