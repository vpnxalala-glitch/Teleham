# Teleham (Web)

Веб-клиент Telegram в браузере — тёмный интерфейс как у Telegram Web.

- Список чатов слева, переписка справа
- Падающий снег
- Удалённые сообщения сохраняются
- История правок

## Запуск на ПК

1. Установи [Python 3.10+](https://www.python.org/downloads/) (галочка Add to PATH)
2. Скачай этот репозиторий (Code → Download ZIP) и распакуй
3. Дважды нажми **`start_web.bat`**
4. Открой в браузере: **http://127.0.0.1:8080**

Или вручную:
```bash
pip install -r requirements.txt
python server.py
```

## Вход

1. Номер с кодом страны: `+79001234567`
2. Нажми «Получить код» — код придёт **в приложение Telegram** (или SMS)
3. Введи код → если попросит, пароль 2FA

Сессия сохранится в `teleham.session`.
