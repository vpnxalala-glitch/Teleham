# Teleham

Клиент Telegram **для ПК** (Windows / Linux / macOS).

## Возможности
- Вход по номеру телефона
- Список чатов и переписка
- **Падающий снег** в окне чата
- **Удалённые сообщения** — сохраняются и показываются
- **История правок** — видно, что было до редактирования

## Запуск на ПК

1. Установи Python 3.10+
2. Открой папку проекта в терминале
3. Выполни:

```bash
pip install -r requirements.txt
python teleham.py
```

На Windows можно дважды нажать `start.bat`.

## Первый вход

1. Введи номер телефона (с кодом страны, например `+79001234567`)
2. Введи код из Telegram / SMS
3. Если есть 2FA — введи пароль

Сессия сохранится в файл `teleham.session` — повторный вход не нужен.
